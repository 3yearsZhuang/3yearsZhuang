## 关于

&nbsp;&nbsp;&nbsp;你好，这里是 **3yearsZhuang**。主要写 TypeScript （我最喜欢TS了!!哦当然不是那个TS）
全栈都做，属于「全干工程师」的那种～。

&nbsp;&nbsp;&nbsp;喜欢做**自己每天都会用**的东西：
比如说一个完全属于你的“小爱”同学、
或者让项目环境配置不再浪费时间的终端应用。

&nbsp;&nbsp;&nbsp;相信「数据自持」——你的数据应该待在你自己机器上。所以我的项目大多本地优先
（local-first），不依赖云端也能跑起来。

&nbsp;&nbsp;&nbsp;平时会逛 GitHub 看有意思的项目，偶尔提点小改动；
处理消息和邮件的时间得看天意。
